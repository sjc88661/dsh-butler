# ADR 0001：独立管家层与原生会话

状态：已实施。当前发布目录为 `0.0.22+layer.2`。2026-10-29 完成独立层验收后，修复剩余存储与测试问题，并再次完成全部 995 项测试及真实运行验证。

## 背景

全局管家控制影响其他原生会话；预算与工具、历史及压缩流程耦合，使一次预检失败可能阻断答复。重复的旧系统上下文和自动加载的目录也扩大输入。零用量可能来自预检失败，不能据此认定配额耗尽。

## 决定

以已登记工作区、隔离提醒及其原生子会话确定管家作用域。管家专用工具注册、提示、技能加载和控制只对该作用域生效；其他会话保留原生执行。

普通管家取消 token 硬预算，以四个常驻工具和按需加载控制输入。隔离提醒保留专用预算和只读限制；全局用量记录仍统计真实用量。用户档案有界注入，完整能力包、待办及其他会话全文不自动注入。

对话来源通过 list/search/read 读取；对话调用使用原生 DSH status/dispatch/cancel，保留队列及幂等语义，受理不等于完成。Codex 对话只读。压缩器使用调用时的 receiver。旧工具声明修复仅覆盖旧预算账本中、已退出管家作用域的历史会话；追加新 series，不改历史或重置账本。

## 后果

管家行为集中在作用域 Seam，外部会话与管家各自可通过原生 Interface 测试。按需加载增加一次发现步骤，但避免默认扩大工具目录。没有硬预算不等于消耗固定：请求次数、工具回包以及被调用对话的原生配置仍决定实际用量。

## 验证

原生端到端验证完成文献题录检索与 DOI 核验，并通过 `butler_dialogue` 分派到独立测试会话；两条会话均以 completed 结束。管家首个 request/header 含 4 个即时工具，按需加载后为 6 个；外部测试会话的真实 request/header 不含管家工具，系统消息不含管家工具指引。普通会话没有写入旧预算账本。

重启后，使用原生 `assemble({ agent, scope: agent, ... })` 复核管家工具仍为 6 个，4 个常驻工具均可即时调用；复核前后模型消息与工具调用数不变。原先验证脚本漏传 scope 得到的空工具投影不代表真实请求状态。

原 Zotero 会话未被激活或发消息，历史声明迁移由回归测试覆盖，未声称已在原会话线上复验。Codex 对话目前只读。摘要和全文不在本次文献成功范围内；arXiv 分支未返回结果。完整证据见 [验收记录](../../../diagnostics/dedicated-layer-20261028/verification.md)。

后续修复了 NTFS 锁目录删除/替换被误判为存储损坏，以及发布前守卫异常被当作 rename 失败继续处理的问题。文献导出 junction 夹具和恢复内存测试已按真实契约修正，数据保护断言保留。最新结果为全量 995/995、30 轮六进程并发验证通过，生产存储状态 healthy。见 [存储修复及完整验收](../../../diagnostics/storage-fixes-20261029/verification.md)。
